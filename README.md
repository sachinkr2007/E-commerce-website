## 🚀 Live Demo & Overview

ShopEase delivers a seamless online shopping experience with realistic product catalog items, INR (₹) pricing, global cart and wishlist persistence, live search autocomplete, promo coupons, and multi-step simulated checkout with printable receipts.

## ✨ Features

- **🛒 Full Cart Management**: Add, update quantity, remove, and clear cart with instant `localStorage` persistence.
- **❤️ Wishlist**: Save favorite items and transfer them to the cart in 1 click.
- **🔍 Live Autocomplete Search**: Real-time dropdown search with instant product filtering.
- **⚡ Quick View Modal**: Inspect detailed product specifications, stock status, and add directly to cart.
- **🎟️ Promotional Coupons**: Apply coupon codes (`SAVE10`, `SACHIN500`, `FESTIVE20`) with instant recalculation.
- **💳 Multi-Step Checkout**:
  - Shipping address form
  - Payment options (UPI / QR Code, Cards, NetBanking, COD)
  - Printable Order Receipt & Invoice
- **🎨 Modern Design System**: Google Fonts (*Plus Jakarta Sans* & *Outfit*), glassmorphic sticky navbar, and responsive layouts for mobile, tablet, and desktop.
- **🔔 Toast Notification System**: Floating feedback alerts for all user interactions.

## 🛠️ Tech Stack

- **Frontend**: React 19, JavaScript ES6+
- **Routing**: React Router DOM v7
- **Styling**: Vanilla CSS (Custom Design System with CSS Variables)
- **Icons**: React Icons (Feather Icons)
- **Bundler & Dev Server**: Vite 8

## 📦 Getting Started Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sachinkr2007/E-commerce-website.git
   cd E-commerce-website
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build for Production**:
   ```bash
   npm run build
   ```

## 🌐 Deploy to Vercel / Netlify

### Deploy with Vercel:
1. Import this repository in [Vercel Dashboard](https://vercel.com).
2. Framework Preset: **Vite**
3. Root Directory: `./`
4. Click **Deploy**!
